video-studio is a personal production pipeline used by one creator to make animated explainer videos about technology, history and the internet. Each episode is scripted, illustrated and rendered by the creator.

What the uploader does

The uploader is a command-line tool that runs only on the creator's own computer. Using the YouTube Data API v3, it:

  • uploads finished episodes to the creator's own YouTube channel, with title, description, tags and an AI-generated-voice disclosure;
  • sets each video's custom thumbnail;
  • creates a playlist per series and adds each new episode to it.

Who uses it

Only the channel owner. The tool is not offered to the public, has no sign-up and does not access any other user's account or data.
