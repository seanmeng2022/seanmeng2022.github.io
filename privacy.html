video-studio uploader is a private, single-user command-line tool. Its only purpose is to let the channel owner upload videos they produced themselves to their own YouTube channel, set thumbnails, and add those videos to playlists on that channel, using YouTube API Services.

Information accessed

When the channel owner authorizes the tool through Google OAuth, it receives an access token and a refresh token for the owner's own Google account, with the scopes youtube.upload and youtube. The tool uses them only to:

  • upload videos and set their titles, descriptions, tags and thumbnails;
  • create playlists on the owner's channel and add the uploaded videos to them;
  • read the owner's channel name to confirm which channel was authorized.

The tool does not read comments, subscribers, analytics, or any data belonging to other users.

Storage

OAuth tokens are stored only on the owner's own computer, in a file readable only by that user. They are never sent anywhere except Google's own servers. The tool keeps a local log of uploaded video IDs so it does not upload the same episode twice.

Sharing

The tool does not collect, sell or share any personal information, YouTube data or Google user data with any third party. It has no other users, no analytics, no cookies and no advertising. This website itself sets no cookies and collects no data.

Revoking access

Access can be revoked at any time on the Google security settings page. Deleting the local token file also stops the tool from accessing the account.

Google and YouTube policies

This tool uses YouTube API Services. Use of YouTube is subject to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
